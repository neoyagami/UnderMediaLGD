# Project artwork

`no-signal.png` is the 640x360 source image for the V4L2 disconnected-input
frame. The supplied default is neutral project artwork with a generic
disconnected digital video cable; it contains no people, characters, product
logos or standard-specific branding.

The image is distributed under the same GPL-2.0-only terms as the driver. The
kernel module embeds a YUYV derivative generated by `make no-signal`.

Users may replace this file before compiling. A replacement must be exactly
640x360. Redistributors are responsible for ensuring that their replacement
artwork can legally be distributed under terms compatible with the driver.
