# Project artwork

`no-signal-penguin.png` is original project artwork for the V4L2 disconnected-
input frame. It depicts a generic penguin and a generic disconnected digital
video cable; it contains no product logos or standard-specific branding.

The image is distributed under the same GPL-2.0-only terms as the driver. The
kernel module embeds a compact YUYV derivative generated by
`scripts/generate-no-signal-asset.sh`.
