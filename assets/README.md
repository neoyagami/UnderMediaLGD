# Project artwork

`no-signal.png` is the square source artwork selected for the V4L2 disconnected-
input frame. `no-signal-penguin.png` is its expanded 1920x1080 version used by
the driver asset generator.

The project artwork is distributed under the same GPL-2.0-only terms as the
driver. The kernel module embeds a 960x540 YUYV derivative generated by
`scripts/generate-no-signal-asset.sh`.
